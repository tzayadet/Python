# Python · Learning & Projects

Repositorio personal de aprendizaje y desarrollo en Python. Reúne apuntes, ejercicios, automatizaciones y aplicaciones de escritorio creadas durante distintas etapas de formación y práctica.

## Contenido

- **Fundamentos y ejercicios:** sintaxis, estructuras de datos, funciones, clases y resolución de retos.
- **Automatización:** scripts para tareas repetitivas y procesamiento de información.
- **Aplicaciones de escritorio:** utilidades con interfaces gráficas.
- **Documentos y datos:** herramientas de comparación, análisis y generación de informes.
- **Proyectos experimentales:** simuladores, juegos, utilidades y pruebas técnicas.

## Ejecución

La mayoría de los scripts se ejecutan con Python 3. Los requisitos varían según el proyecto. Revisa los imports del archivo antes de instalar dependencias.

Ejemplo:

```bash
python nombre_del_script.py
```

Para proyectos con dependencias externas, crea un entorno virtual:

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
source .venv/bin/activate
```
